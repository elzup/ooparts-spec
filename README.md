# ooparts-spec

## What is ooparts

Useful by accident. Designed without purpose.

需要や正解を前提としない、異質な挙動を持つ実験的成果物です。

> 名前は OOPArts (Out-Of-Place Artifacts / オーパーツ) から。
> 英語では単数形の OOPArt が一般的ですが、個々の作品ではなく「場違いなものたちの集まり」を指すため、あえて複数形の s を付けています。
